## Summary

Fix the fail-closed stored-telemetry response parser after read-only run `31292196784` returned `telemetry-query-shape-invalid`.

Cloudflare's official telemetry query schema marks `events.count` optional. The first implementation incorrectly required it even when a complete event array was present.

## Change

- Accept an omitted aggregate count only when fewer than the 2,000 requested rows are returned.
- Continue rejecting an explicit total greater than returned rows.
- Reject invalid counts, totals smaller than returned rows, and any response at the 2,000-row boundary where truncation is ambiguous.
- Add positive optional-count coverage and negative boundary-truncation coverage.

No endpoint, permission, encryption, redaction, input, or production control behavior changes.
