# 2026-03 — SDK breadth; four repos born

- Broker renamed relay-pty → **agent-relay-broker** (v2.3.16); v3.1.0 switches
  to provider-driven headless runtime.
- OpenClaw launches as a lockstep parallel release line (118 tags through May).
- Multi-workspace lands end to end: deterministic workspace key from
  user+directory, token rebinding on switch.

  **A2A protocol transport**, adapters for OpenAI Agents, LangGraph, Google
