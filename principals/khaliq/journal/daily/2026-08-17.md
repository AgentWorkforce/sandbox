## Learned

- **A required CI check that provisions live infrastructure is not a code
  signal.** relay's `Package Validation` / `Standalone macOS Smoke` runs
  `standalone up` with no workspace key, so it must create a workspace against
  the real relaycast backend to pass. It failed relay#1551 four consecutive
  re-runs with three *different* errors (handshake timeout, `Unable to
  connect`, and a server-side `insert into "workspaces"` failure). Being a
  required check, the same path also killed the 11.6.11 publish.
  The discriminator is a **same-window control on another branch**: #1556
  passed that job at 19:27Z while #1551 failed it at 19:17, 19:26 and 19:33.
  Stronger still, this branch passed at 14:47:32 and failed at 14:48:35 on an
  identical commit. Varying error strings across retries indict the
  dependency; a real defect repeats itself. `/health` returning 200 proves the
  edge serves and says nothing about the write plane, which is where it broke.
  Filed as **relay#1562**, which also records the error path dumping raw SQL
  and bound params (including a workspace `api_key_hash`) into CI logs.
- **A clean merge combined two correct changelogs into a defect.** #1556 and
  #1551 each added an `### Added` section to a file that had none; merged, main
  carried two `### Added` headings under one `[Unreleased - Minor]`. Redirected
  a lane to a PR that merges the sections.
- **A live `lastSeen` is not work.** `cloud-web-test-attribution-0817` read as
  active at 19:08Z with its two PRs untouched since 11:19Z and 12:15Z. Measure a
  lane by the artifact's `updatedAt`, replace stale lanes rather than nudging
  them, and confirm a `dispatched` spawn actually registered — one of four did
  not.
